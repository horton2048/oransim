# Maya — 设计 Brief（粘给 Claude Design）

> 把这份整段粘进 claude.ai/design，并上传同目录的 `sample-data.json`。

## 你要设计什么

**Maya** 是一个营销模拟产品的 Web 界面。用户输入**一条社媒广告创意 + 投放计划**，Maya 用 **10 万个统计模拟消费者 + 100 个 LLM 驱动的「灵魂」人格**，模拟中国社媒（抖音 / 小红书）真实用户，**60 秒预演**这条投放会跑出什么结果：CTR / CVR / ROI、用户的真实情感反应与吐槽、14 天的传播扩散曲线，并能拖动滑块做「反事实」推演（如果预算翻倍 / 平台分配换一换，结果怎么变）。

一句话价值：**「投放前先让一百万虚拟消费者替你试一遍。」**

- **产品名**：Maya（界面各处用 Maya；不要出现 oransim / 旧名）
- **受众**：品牌方、投放操盘手、营销策划——专业但不一定懂数据科学
- **语言**：**简体中文优先**（KPI 缩写如 CTR/CVR/ROI 保留英文）
- **平台**：桌面 Web 为主，需响应式

> 命名钩子（可选用于美学）：Maya 在梵文里意为「幻象 / 被造出来的世界」——一个由模型造出来、却像真的一样会思考会买单的消费者世界。可以让它呼应「真实与模拟之间」的气质。

## 美学方向（请大胆选一个并贯彻到底）

约束：**深色**、数据密集但不杂乱、要有**科学可信度**（这是预测工具，不是营销 landing page）、中文排版要讲究。

请避免 AI 套路货：不要 Inter/Roboto/Arial，不要白底紫渐变，不要千篇一律的卡片网格。

给你三个备选基调，**任选其一并彻底执行**（或自创一个更贴切的）：
1. **天文台 / 遥测控制台**——像在观测一个活的消费者星系。深空底色、精密的网格与刻度、单色高光 + 一个锐利强调色、等宽数字字体、细腻的发光与扫描线。
2. **科研仪表 / 示波器**——冷静、克制、信息密度高。像高端测量仪器的屏幕，数据为王，动效极简而精准。
3. **活体人群 / 神谕**——把「十万个灵魂在思考」做成有机的、会呼吸的氛围。粒子涌动、暖冷对撞，强调「这些模拟用户是活的」。

**字体**：选一款有个性的中英显示字 + 一款干净的正文字；数字大量出现，配一款好看的等宽/表格数字字体。
**动效**：重点放在「一次编排到位的加载揭示」（staggered reveal）和预测出结果那一刻的高光时刻，而不是到处撒微动效。

## 数据从哪来

上传的 `sample-data.json` 是一次**真实**的 `/api/predict` 响应。**用它的真实字段和量级来布局**，不要自己编数字。关键字段：
- `kpis`：impressions ~204万、clicks ~2.7万、conversions ~5382、ctr 0.0133、cvr 0.199、roi 2.03、revenue、cost
- `per_platform.douyin / .xhs`：每平台一套 KPI，且带 `_std` 不确定性（可做误差条/置信区间）
- `soul_quotes[]`：每条是一个模拟用户的发言——persona_oneliner（如「22岁女·学生·四线」）、will_click、feel（心动/购买冲动/好奇/无感/厌恶）、reason、comment、purchase_intent_7d
- `predicted_sentiment`：sentiment_distribution（正/中/负）、net_sentiment_score、high_intent_pct、feel_breakdown、key_opinion_themes
- `lifecycle`：14 天扩散——day_axis、paid_daily、organic_daily、total_daily、peak_day、organic_share
- `macro`：宏观因子（节假日/时段/天气/情感乘数、LLM 校准统计）

## 第一轮只做主仪表盘

先别铺开所有功能。第一轮交付**主仪表盘**的整体视觉与布局：

- **顶栏**：Maya 品牌标识 + 系统状态（10 万消费者 / 100 灵魂 / LLM 在线，数据见 `/api/health`）
- **左栏 · 投放台**：创意输入框 + 预算滑块（¥5k–500k）+ 平台分配（抖音/小红书）+ KOL 领域选择 + 一排预设按钮（轻量/爆款/危机/完整）+ 高级参数折叠区。底部一个醒目的「▶ 开始预演」
- **中心 · 预测**：大号 KPI 网格（impressions/clicks/conversions/CTR/CVR/ROI），每个带 vs 基线的 delta 和不确定性；下面分平台对比 + Hawkes 14 天曲线
- **右栏 · 民意**：情感分布 + 净情感分 + 高意向占比，下面是滚动的「灵魂语录」卡片流（每张一个模拟用户的脸谱 + 是否点击 + 一句吐槽 + 7日购买意向）
