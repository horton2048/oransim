# Maya — 信息架构 & 逐区规格

主界面是**三栏 + 中心多视图**的单页应用。以下是完整区块清单，标注**保留/重做/占位/砍**，给 Claude Design 做后续轮次。

## 整体布局

```
┌─────────────────────────────────────────────────────────────┐
│ 顶栏：Maya logo · 系统状态(消费者/灵魂/LLM) · 端口/设置        │
├──────────┬───────────────────────────────────┬──────────────┤
│ 左栏     │ 中心：预测 & 反事实（多视图切换）   │ 右栏          │
│ 投放台   │                                   │ AI 民意 & 情感 │
│ (表单)   │                                   │ (灵魂语录)     │
└──────────┴───────────────────────────────────┴──────────────┘
```

## 左栏 · 投放台（表单）— 全部重做

- 创意输入：`caption` 文本框 + 视觉风格下拉（bright/dark/minimal/flashy）+ 配乐情绪下拉（upbeat/calm/asmr/dramatic）+ 明星代言勾选
- 预算滑块：¥5k–500k，默认 ¥5万
- 平台分配：抖音 % / 小红书 %（联动，和为 100%）
- KOL 领域：美妆/母婴/数码/美食/穿搭/健身/理财/旅行
- **预设按钮**（一键填表）：⚡轻量 · 🔥爆款 · ⚠️危机 · 🧠完整
- 高级参数折叠区：受众定向（年龄段/性别/城市层级）、天气与舆情、灵魂采样数 n_souls、是否启用真 LLM、各种前沿开关
- 反事实滑块：抖音% / 小红书% / 总预算 —— 拖动实时重算

## 右栏 · AI 民意 & 情感 — 全部重做

- 情感分布直方图：`predicted_sentiment.sentiment_distribution`（正/中/负）
- 净情感分 `net_sentiment_score`、高意向占比 `high_intent_pct`、均值购买意向
- feel 分布 `feel_breakdown`（心动/购买冲动/好奇/无感/厌恶）
- 关键舆论主题 `key_opinion_themes`（top 6，主题 + 计数）
- **灵魂语录卡片流**（重头戏）：`soul_quotes[]` 每条一张卡——人格一句话画像、是否点击（绿/红）、feel、reason、comment、7日购买意向条。可分页/无限滚动

## 关键交互流

1. 填表 / 点预设 → 点「▶ 开始预演」→ `POST /api/predict`（30–120s，需 loading 态）
2. 出结果 → KPI / 曲线 / 灵魂语录 / 情感同时渲染
3. 拖反事实滑块 → `PATCH` + `counterfactual` → KPI delta + CATE 实时更新
4. 切视图 → 懒加载对应数据
5. 「刷新灵魂解释」→ 重采样语录

## 给设计的提示
- **loading 态很重要**：预测要等 30–120 秒，这段「正在询问 N 个虚拟消费者…」的过程本身就是产品的魔法时刻，值得专门设计（进度叙事 / 灵魂逐个亮起）。
- **不确定性是卖点**：每个 KPI 都有 `_std`，把置信区间做出来 = 科学可信度。
