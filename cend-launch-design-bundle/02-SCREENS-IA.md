# 会不会火 — 信息架构 & 逐屏 / 逐档规格

主体是**单列、移动优先的一条主线**：落地 → 揭幕 → 结果卡（三档变形）→ 回放。不是三栏专业操作台。

## 整体流

```
┌──────────────────────────────┐
│ 顶栏：会不会火 · 状态点(LLM在线)  │
├──────────────────────────────┤
│ ① 落地页                       │
│   一句话价值                    │
│   ┌────────────────────────┐  │
│   │ 说说你的产品想法…        │  │  ← 大输入框
│   └────────────────────────┘  │
│            ▶ 揭幕              │
├──────────────────────────────┤
│ ② 揭幕动画（高光时刻）          │  ← 推演逐步亮起
├──────────────────────────────┤
│ ③ 结果卡（A / B / C 变形）      │
│   [档位徽章] [置信区间]         │
│   「这是带标注不确定性的情景      │
│     推演，不是预测」            │
│   …分档内容（见下）…           │
│   ▶ 看电影回放                 │
└──────────────────────────────┘
```

## ① 落地页 — 全新

- 一句话价值 + 大输入框（`idea_text`，一句话即可）+「▶ 揭幕」主按钮。
- 留白、克制、邀请感。可放 2–3 个示例想法（点了自动填入）降低冷启门槛。
- **不要**在这里堆参数表单。高级项（预算、平台、受众）默认折叠或干脆放到结果后再调。

## ② 揭幕动画 — 全新（魔法时刻，重点设计）

- 点「揭幕」→ 到结果之间会等若干秒（后端要跑推演）。**这段等待要做成叙事**：推演逐步亮起 / 追光落下 / 「正在推演……」的诚实进度。
- 这是产品的高光，值得单独设计，不要只是一个转圈。

## ③ 结果卡 — 三档变形（**设计灵魂，请给备选**）

每档都**常驻**：档位徽章（A/B/C）、置信区间、「推演非预测」声明、来源三色假设回显。三档**一眼可辨可信度**。

### A 档 · 校准模拟（数据来源 `sample-A.json`）— 精确、笃定

| 区块 | 字段 | 处置 |
|------|------|------|
| **指标** | `metrics.{unique_reach,trials,adopters,adoption_rate,revenue,payback}` 每个带 `p35/p50/p65` | 核心。分位带做成「区间 + 中位」，P35 标**「下行情形」** |
| **90 天时间线** | `timeline.daily_adopters / daily_revenue` + `peak_day/half_life/saturation_date` | 面积/折线，标出 peak_day 与饱和点 |
| **谁会买** | `who_buys.cate_segments`（性别/年龄/城市层级分布）+ `persona_quotes[]` | 人群画像图 + 「灵魂语录」卡片流：是否会试、愿付价、**原话异议（不润色）**、7 日意向 |
| **什么会出问题** | `what_breaks.intervention_cards[]` + `audit_risk` + `season_window` | 干预叙事卡：涨价/不请达人/竞品跟进；竞品卡固定标**「这是分支不是预测」** |

### B 档 · 未校准结构化（数据来源 `sample-B.json`）— 同结构，收一档底气

- **与 A 同样的区块布局**，但视觉上明显「降一档确定性」。
- 必须可见：`tier_label="B · 未校准结构化"`、`uncalibrated:true` 的**「未校准」徽章**、`grounding_confidence` 更低、分位带 `band_widened:true`（**区间明显更宽**）。
- 设计要点：让用户一眼明白「这是同一套推演，但底气不足、读数仅供参考」。

### C 档 · LLM 情景推演（数据来源 `sample-C.json`）— 定性，强烈区分于 A

- **没有 `metrics` 分位带**（`no_kpi:true`）。**绝不出现精确 KPI 数字外观。**
- 改为 `scenario` 五块：
  | 区块 | 字段 | 呈现 |
  |------|------|------|
  | 市场盘子 | `scenario.market_sizing`（`range_low/high` + `magnitude_only`） | **数量级 + 超宽区间**，逐字标「数量级估计，非校准」 |
  | 买家画像 | `scenario.buyer_personas[]`（who / jobs / willingness / objection） | 定性人物卡，不带数字 |
  | 渠道 | `scenario.channels[]`（channel / fit） | 渠道适配定性评级 |
  | 采纳形状 | `scenario.adoption_shape`（shape + narrative，`no_numbers:true`） | **曲线的形状与拐点逻辑的叙事**，不画逐日数字 |
  | 关键风险 | `scenario.key_risks[]` | 风险清单 |
- 视觉气质：像「情景剧本 / 研判手记」，不是仪表盘。

## ④ 「看电影回放」入口 — 复用现成模块

- 结果卡上一个「▶ 看电影回放」按钮，拉起 **diorama 微缩沙盘**回放（重型可视化，**我已有现成模块**，你只需设计**入口按钮 + 容器位置**，回放本体我来挂）。
- **C 档无微缩沙盘**：设计一个优雅的降级/隐藏（如按钮不出现，或换成「本档为定性推演，无沙盘回放」的说明）。

## 砍 / 不做

- ❌ **pro 操作台**（旧 `launch-console.html`）作为独立入口——**整个移除**。本产品只有这一条 C 端主线。
- ❌ 落地页的大参数表单——克制，别把专业操作台搬过来。

## 给设计的提示
- **可信度是卖点，不是免责声明**：把「这档有多可信」做成正面的设计语言（A 笃定 / B 谨慎 / C 坦诚是猜测），而不是藏在小字里。
- **揭幕等待 = 魔法**：那几秒推演过程值得专门设计。
- **三档同框对比**（可选加分）：若能让用户感到「我的想法被分到了哪一档、为什么」，会非常加分。
