# 会不会火 · 上市预测 — 设计 Brief（喂给 open-design）

> 把这份整段作为 brief 输入，并上传同目录的 `sample-A.json` / `sample-B.json` / `sample-C.json`。

## 你要设计什么

**「会不会火」** 是一个**上市预测**的 C 端产品。用户输入**任何一个产品想法**（一句话即可，如「一款保湿面膜，89 元，主攻小红书种草」），点一下「揭幕」，得到一份**诚实标注**的预测：会不会火、谁会买、什么会出问题，还能「看电影回放」看一场推演的微缩沙盘。

一句话价值：**「上市前，先让模型替你推演一遍——而且它会诚实告诉你哪些是算的、哪些是猜的。」**

- **产品工作名**：会不会火（品牌名未定，你可提方案；**绝不出现 oransim**）
- **受众**：要上新品的创业者、品牌方、产品经理——懂自己的产品，不一定懂数据科学
- **语言**：**简体中文优先**（KPI 缩写如 CTR/ROI 保留英文）
- **平台**：移动优先的单列 C 端体验，需响应式（桌面同样好看）。**注意：这不是密集的专业操作台，是一条干净的消费级主线。**

## 灵魂 · 三档分诊（这是本设计的核心，不是配角）

老产品是「保安」：只认消费品，其它**硬拒**——还把「校准的精确预测」和「未校准的猜测」混在同一套视觉里，让人误以为猜测也很精确。

新产品是「**分诊台**」：任何想法都不拒，按可信度分流三档。**你最重要的设计任务，是让 A / B / C 三档的结果卡，一眼就能看出它们的「可信度」不同——而绝不能让 C 档的猜测，长得像 A 档的精确预测。**

- **A · 校准模拟**——有底气。精确的分位带数字（P35/P50/P65）、90 天逐日时间线、真实 persona 引语。视觉可以「精密、笃定、数据感强」。
- **B · 未校准结构化**——同样的结构，但**明示「未校准」**：区间明显更宽、置信度更低、带一枚「未校准」徽章。视觉要比 A **收一档底气**——像同一台仪器但标了「读数仅供参考」。
- **C · LLM 情景推演**——**根本不给精确数字**。只给定性的情景：市场盘子（数量级 / 超宽区间）、买家画像、渠道、采纳曲线的**形状**（不是逐日数字）、关键风险。视觉必须与 A **强烈区分**——更像「一份会议白板上的推演手记 / 情景剧本」，而不是仪表盘。**C 档不得借用 A 档的精确数字外观。**

> **诚实标注合约（贯穿全程的红线）**：
> 1. 每份结果都带**档位徽章**（A/B/C）和**置信区间**。
> 2. 报告里逐字常驻这句：**「这是带标注不确定性的情景推演，不是预测」**。
> 3. 假设字段按**来源三色**标注：用户原话 / LLM 推断 / 系统默认（数据见 sample 的 `header.assumptions[].source`）。
> 4. C 档与 A 档**视觉强区分**；B 档介于其间；合成 / 未校准字段**逐个打标**。

**请把「三档如何视觉区分」做成几套备选方案给我选**——这是你交付的重点。

## 美学方向（大胆选一个并贯彻；但「三档区分」高于美学）

约束：**诚实科学感**（这是预测工具，不是营销 landing page）、移动优先单列、中文排版讲究、揭幕那一刻要有**高光时刻**。

请避免 AI 套路货：不要 Inter/Roboto/Arial、不要白底紫渐变、不要千篇一律的卡片网格。

给你三个备选基调，**任选其一彻底执行**（或自创更贴切的）：
1. **占卜 / 揭幕**——输入想法像许愿，「揭幕」像翻开一张牌。深色、克制、一束追光打在结果上。三档用「光的笃定程度」区分：A 锐利聚焦、B 微微发散、C 朦胧手绘感。
2. **科研仪表 / 推演台**——冷静、信息密度适中、像高端测量仪。A 是校准好的读数，B 是同仪器标「未校准」，C 切换到「定性情景」模式（仪表收起，换成情景卡）。
3. **战情推演 / 沙盘**——呼应「看电影回放」的微缩沙盘气质。A/B 是带数字的战报，C 是「敌情研判」式的定性研判卡。

**字体**：一款有个性的中英显示字 + 一款干净正文字；数字多，配一款好看的等宽/表格数字字体。
**动效**：重点放在**「一键揭幕」的揭示瞬间**（staggered reveal）和结果出现的高光，而不是到处撒微动效。

## 数据从哪来

上传的三个 sample 是三档的**字段和量级**参考。**用它们的真实字段布局，不要自己编数字。** 关键字段（详见 `03-API-CONTRACT.md`）：

- **A 档（`sample-A.json`，真后端捕获）**：
  - `header.assumptions[]`：回显的产品假设，每条带 `source`（用户原话/LLM 推断/系统默认）——三色标注的素材。
  - `metrics`：`unique_reach / trials / adopters / adoption_rate / revenue / payback`，每个带 `p35/p50/p65` 分位带，`p35_label="下行情形"`。
  - `timeline`：90 天 `daily_adopters / daily_revenue`，`peak_day / half_life / saturation_date / market_potential_m`。
  - `who_buys`：`cate_segments`（有效人群画像：性别/年龄/城市层级分布）+ `persona_quotes[]`（真实模拟用户：是否会试 `will_try`、愿付价 `would_pay_cny`、**原话异议 `objection`**、7 日购买意向）。
  - `what_breaks`：`intervention_cards[]`（涨价 30% / 不请达人 / 竞品跟进——每张带 `delta`、`branch` 标「这是分支不是预测」）+ `audit_risk` + `season_window`。
- **B 档（`sample-B.json`）**：与 A 同结构；注意 `grounding_confidence` 更低、`uncalibrated:true`、分位带 `band_widened:true`、徽章「未校准」。
- **C 档（`sample-C.json`）**：**没有 `metrics` 分位带**；改为 `scenario`：`market_sizing`（数量级 + 超宽区间）、`buyer_personas`、`channels`、`adoption_shape`（曲线**形状**叙事，无逐日数字）、`key_risks`。带 `no_kpi:true`。

## 这一轮交付什么

设计**整条主线**的整体视觉与布局，并就「三档区分」给我几套备选：

1. **落地页**：一句话价值 + 一个大输入框（「说说你的产品想法」）+ 一颗醒目的「▶ 揭幕」按钮。轻量、留白、像在邀请你许个愿。
2. **揭幕动画**（高光时刻）：点击后到结果出现之间的**揭示过程**本身就是魔法——值得专门设计（推演逐步亮起 / 追光落下）。
3. **结果卡（随档位变形）**：A / B / C 三种形态，**一眼可辨可信度**。这是重点，请给几套备选。
4. **「看电影回放」入口**：结果卡上一个按钮，拉起 diorama 微缩沙盘回放（回放本身我已有现成模块，你只需设计**入口**和容器位置；C 档无沙盘时如何优雅降级/隐藏）。
5. **诚实标注**：档位徽章、置信区间、「推演非预测」声明、来源三色——在每屏都在场。
